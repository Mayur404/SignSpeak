📘 ASL & Gesture Reference Guide

Hold a hand shape steady for 0.5 seconds to type. The system recognizes the full ASL alphabet (A-Z), digits (0-9), and special control gestures:

Special Navigation Gestures:
• Thumbs Up = Add Space (finishes the current word and triggers word speech)
• I Love You (🤟) = Add Period (finishes sentence and triggers full speech)
• Open Palm Wave = Backspace (deletes previous letter)

🌐 5G Lab & Network Architecture

SignSpeak is optimized for the private 5G Multi-access Edge Computing (MEC) lab at IIIT Dharwad (EC368). The Sparsh camera transmits over the lab's 5G network to the edge server VM (172.16.0.10).

⚠️ Finding the 5G Camera WAN IP:
1. The 5G modem assigns a dynamic WAN IP upon reconnecting (e.g. 10.101.0.70).
2. The modem admin page (192.168.128.1) is NOT accessible from Wi-Fi or over 5G.
3. You MUST connect your laptop directly to the modem via an Ethernet cable.
4. Set your laptop static IP to 192.168.128.100, mask 255.255.255.0.
5. Open http://192.168.128.1 in your browser, check the 5G WAN IP, and update CAMERA_HOST in .env.

Direct RTSP Stream Paths (Sparsh Topsvision v2.1):

Substream (720p - Recommended):
rtsp://admin:admin123@10.101.0.70:554/avstream/channel=1/stream=1.sdp

Mainstream (4K):
rtsp://admin:admin123@10.101.0.70:554/avstream/channel=1/stream=0.sdp
